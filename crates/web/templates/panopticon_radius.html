{% call macros::icon("host") %} NAS clients

The switches/APs allowed to talk to the RADIUS server, each with its shared secret. CoA is how Panopticon tells a NAS to re-authorize a session when a device's trust changes or its port is quarantined or released, so the change applies now instead of at the next login: Disconnect (RFC 5176, most switches and controllers; the device briefly drops) or Reauthenticate (Cisco CoA; no drop). The NAS must accept dynamic authorization from this server's address with the same shared secret (Cisco: aaa server radius dynamic-author), on UDP port 3799 unless you set another.
