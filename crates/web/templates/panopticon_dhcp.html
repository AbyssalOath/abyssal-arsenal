{% call macros::icon("shield") %} DHCP servers

Every DHCP server Panopticon's capture has seen: from the server clients name in their DHCP requests (which also arrive through relays: add this server as an extra ip helper-address), and from server replies on the captured segment. With the allowed list below filled in, any other server is a rogue: an alert goes to the rogue-device recipients and the audit log, once a day per server, and the policy engine's Rogue DHCP server trigger can quarantine the device that answered: by the MAC its replies came from, never by an address a packet names, since any device can name any address. A rogue that's only been named by clients (or seen through a relay) is unconfirmed and never enforced. Empty = detection off. Panopticon's own registration DHCP server is always allowed.
