Install tokens

Any install token enrolls hosts everywhere: the Windows exe and MSI (AAT=), abyssal-agent install --aat on Linux, and the one-liners. It also proves this control plane's certificate to a new host, so no CA fingerprint is needed. Use the default token for your standing deploy packages, and an additional token for a rollout you want to label, limit in time, count, or revoke on its own. Hosts a token enrolled keep working when it's revoked or rotated.
