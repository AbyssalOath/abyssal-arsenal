{% call macros::icon("host") %} Deployment tokens (mass rollout)

A reusable token for rolling the agent out to many machines at once -- paste the generated command into PDQ Deploy, a GPO startup script, or Intune. Every machine that runs it enrolls automatically under its own hostname. Unlike the single-use token above, one deployment token provisions every host it reaches until it expires or you revoke it.
