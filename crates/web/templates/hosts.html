{% call macros::icon("host") %} Agent install token (AAT)

One reusable token for this control plane, like a CrowdStrike CID: put it in your PDQ Deploy, Intune, or GPO package once and every machine that runs the installer enrolls under its own hostname. It also proves this control plane's certificate to new hosts, so no CA fingerprint is needed. It never expires -- rotate it if it leaks; hosts it already enrolled keep working.
