{% call macros::icon("elevate") %} Apotheosis elevation window

How long a host stays elevated after a successful sudo password prompt, with no further action needed, before it drops back to unprivileged. Applies to new elevations only -- hosts already elevated keep whatever window was in effect when they were elevated.

{% call macros::icon("danger") %} High-risk storage operations

Gates Ossuary's most dangerous operations -- partition table create/delete, RAID array create/stop, LVM physical volume/volume group/logical volume create and remove, and creating a filesystem. A single wrong device path in any of these can destroy a disk instantly and irrecoverably. Off by default; this is a second, deliberate layer on top of (not instead of) the type-to-confirm each of those operations still requires individually.

Currently: {% if high_risk_storage_ops_enabled %}Enabled {% else %}Disabled{% endif %}

{% call macros::icon("danger") %} Host network isolation

Gates Inquest's full host isolation (blocks all network traffic except the control plane's own connection). Unlike every other destructive operation this platform dispatches, a wrong edge case here (NAT, a DNS-based control-plane address, a multi-homed host) can sever the agent's own connection back to the control plane with no remote way to undo it -- recovery would need physical or console access to the host. Off by default; this is a second, deliberate layer on top of (not instead of) the type-to-confirm the operation still requires.

Currently: {% if host_isolation_enabled %}Enabled {% else %}Disabled{% endif %}

{% call macros::icon("audit") %} Thanatos background monitoring

An unattended, fixed-interval sweep that scans every connected host's security logs, persists what it finds, and can raise correlation alerts on its own -- nobody has to click anything. Off by default: this reads and stores security-log content across your whole fleet automatically once enabled. Manual, admin-triggered scans from the Thanatos page work regardless of this setting; it only controls the unattended sweep.

Currently: {% if thanatos_monitoring_enabled %}Enabled {% else %}Disabled{% endif %}

{% call macros::icon("audit") %} Thanatos alert recipients

Comma-separated email addresses notified when Thanatos's correlation sweep raises a finding, sent through whatever notification provider is configured (SMTP today, set via environment variables). An alert is still recorded and shown on the Thanatos page even with no recipients set -- this only controls whether it's also actively pushed out.
